# User guide

This guide is for people who build flows in Document Engine and run them on files. It explains every screen, every building block and every option, in the words the screens use. You do not need to know how the engine works inside to follow it; where that background helps, the pages link to [How it works](../how-it-works/README.md).

If you are new, read [Concepts](../start/concepts.md) first, then follow [Build a flow](build-a-flow.md) from start to finish. The other pages are reference: open them when you need a detail.
